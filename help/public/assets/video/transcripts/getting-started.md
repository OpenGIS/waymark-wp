# Getting Started

**00:00:03.923 – 00:00:22.338**

Every Waymark Map gets its own page on your site. This one carries a route, the places along it, and the photographs that go with them. There is no separate map tool to learn and no embed code to wrestle with: it is a live map, panned and zoomed like any other, inside the pages you already publish.

**00:00:23.638 – 00:00:42.883**

Click a pin and the place opens: whatever that Marker carries — a photograph, a description, the Type it belongs to. Some are places to eat, some camps and warnings, some just a view worth stopping for. The Type gives each one its icon and colour, and keeps thirteen pins readable at a glance.

**00:00:46.254 – 00:01:10.084**

A Map holds more than Markers. Lines draw the route, with arrows for direction. Areas shade a lake shore or a campground. All three take their look from Types defined once, so every feature stays consistent without touching each one. The basemap is a choice too: switch it, and the terrain redraws underneath the work, with every Marker and line still where you left it.

**00:01:14.751 – 00:01:29.446**

Routes carry data as well as looks. The elevation profile follows the climb, and the whole route can leave with the visitor as a GPX file, ready for a phone or a watch. Nobody has to screenshot the map to take it with them.

**00:01:31.793 – 00:01:50.548**

Maps that belong together can be gathered into a Collection. This one holds three routes around Vancouver Island, and a single page shows them all: the same maps, the same pins, one place to browse. A Map joins a Collection from the Editor, and the page follows. Nothing is duplicated.

**00:01:56.153 – 00:02:12.728**

All of it is built here, in the Editor you already use — the same Map you just saw, from the inside. The toolbar places Markers, draws Lines and shades areas. Click a feature and its popup becomes a form: a title, an image, a description. Change it, press Update, and the public page follows.

**00:02:14.055 – 00:02:25.530**

Then paste the Map's Shortcode into any page or post. That is the whole loop: build it here, and it appears there, on a site you already run. No export, no upload, no second copy to keep in step.
