# Getting Started

**00:00:02.692 – 00:00:20.987**

Waymark puts an interactive map on your WordPress site. A Map can be a route, a set of places, or an area you want to show. Everything starts under Maps: each row is a Map you can open and edit, and Add New Map creates another. The Maps already here show what a finished one can hold.

**00:00:27.239 – 00:00:49.374**

Open Cape Scott Trail. The whole thing is one Map: the route as a Line, waypoints as Markers, and shaded areas as Shapes. They all belong together, and the toolbar on the left adds and edits each kind. The Types come from Settings, so every Map draws on the same set. Click a feature to open its popup: a title, an image and a description.

**00:00:51.407 – 00:01:05.717**

Every Map also has a Shortcode, waiting in the sidebar. Copy it into any page or post and that Map appears there. When the Map changes, the page follows. That is the whole path: from editing the Map to the page your visitors read.

**00:01:09.008 – 00:01:12.448**

The same Map, embedded in a page, as a visitor sees it.

**00:01:13.701 – 00:01:21.701**

No admin bar, no editing tools: just the title, the map and its attribution. Visitors can pan and zoom it freely.

**00:01:25.519 – 00:01:37.834**

Collections group Maps. Vancouver Island holds three, with Backpacking and Day Hikes nested beneath it. Use a Collection when related Maps belong together, so the library stays organised as it grows.

**00:01:39.058 – 00:01:53.489**

To go further, the Docs menu opens the documentation site. Begin with Creating Your First Map: it walks through adding a Map, placing a Marker, and publishing it to a page. Take your time with the first one; everything else can wait until you need it.
