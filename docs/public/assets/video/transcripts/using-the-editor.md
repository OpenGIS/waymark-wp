# Using the Editor

**00:00:02.681 – 00:00:16.721**

The Map Editor is where a Map is built. The route and its Markers sit on one map, saved with the post. The tool rail runs down the left. Open a Map from Waymark, under Maps, and the Editor loads at zoom ten with thirteen Markers.

**00:00:17.456 – 00:00:38.501**

Five tools draw on the Map. Marker places a point. Line draws a route, click by click. Rectangle and Polygon draw areas. Circle draws a radius. The rail also holds image upload and file import. Click any feature to open the same editor popup and give it a title, an image and a description.

**00:00:39.818 – 00:01:04.878**

This is San Josep Bay, one of six Photo Markers. Its popup is the editing form: Marker Type, Title, Image URL, Description, coordinates, Duplicate and Delete. The Type is Photo, so the Marker shows a camera. The description field is rich text. The image is already attached, and the coordinates are a read-only label.

**00:01:06.191 – 00:01:22.586**

The Marker title is misspelt. Select it and type San Josef Bay, with an f. The Marker data updates when the field loses focus. Nothing reaches WordPress until the Map is updated. The rest of the Marker stays as it was.

**00:01:26.183 – 00:01:40.068**

The Marker form has no save button. The change is already in the Map data. Press Update and WordPress stores the whole Map. The notice confirms the post is updated. The public Map reads that stored data.

**00:01:42.464 – 00:01:53.679**

The public Map is the same Map, seen by a visitor. The title and featured image come first, then the Map. It has the same route, the same Markers and no editing controls.

**00:01:54.940 – 00:02:03.855**

**00:02:05.140 – 00:02:15.450**

Open San Josef Bay. The Marker now shows the corrected title, with its Photo Type and image. The Type and image are the same properties the Editor holds.

**00:02:16.176 – 00:02:28.601**

The loop is short: edit the Marker, press Update, and the public Map follows. A fresh page load shows the change; a page already open needs a reload. Nothing else changes.
