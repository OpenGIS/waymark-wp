## editor

This Map carries Markers, Lines and Shapes. The Markers use six Types: Photo, Beer, Alert, Food, Camp and Information. The long green route is a Line of the Green Type, with direction arrows along it. The filled areas are Shapes: a green area at Nahwitti Lake, and a blue circle at Holberg. Each Type is defined once, in Settings.

## settings-markers

Marker Types live in Settings, under Markers. The list holds six Types. A row defines the label, the shape, the size, the background colour and the icon. The Beer row here is the definition for both Beer Markers on the Map. Every Marker of that Type uses the same row.

## settings-lines

Lines have their own list. Each row is a Line Type: the label, the colour, the weight and the opacity. The row you see is Red, a definition only; the route on this Map is Green. The Green Type is three pixels at 0.7.

## front-map

The public Map is the same Map, seen by a visitor. The title and featured image come first; the Map sits below.

## front-features

Here are the same features. The Markers keep their icons and colours. The Shapes keep their green and blue fills. Nothing is restyled for the public view; the Types supply the style.

## front-route

Close the elevation profile and the route shows its Type: green, at the same weight and opacity.

## front-type-label

Hover a Marker and the tooltip shows the Type in brackets, then the title: Photo, The Shoe Tree. The icon and background come from the Photo Type. The Type name is part of what a visitor reads.

## types-shared

A Type is defined once. Every Marker, Line and Shape that uses it takes the same style, on the Editor and on the public Map. The style lives in one place, so features of the same Type stay consistent.
