## settings-basemaps

Settings is where the site is configured once. A row of links at the top opens a settings tab for each area, from Basemaps and Types to Meta and Advanced. Basemaps is open: two are defined here, and every Map draws its layer switcher from this list. A Shortcode can name a single basemap instead.

## basemaps-footer

Open Street Map and Open Topo Map each have a name, a tile URL, attribution and a maximum zoom. The footer is explicit: the first listed is the default for every Map, unless a Shortcode names another. Visitors can switch between them, and dragging the rows changes the order.

## settings-markers

Marker Types are the next shared list. This site defines six: Beer, Food, Photo, Alert, Information and Camp. A Type is not a per-Map choice; it is a style every Marker of that Type can use.

## marker-row

Each row sets the Marker Label, the Shape, the Size and the Background colour, then the Icon Type, the Icon Name and the Icon Colour. The Photo row uses a camera icon and a slate colour. Every Photo Marker on every Map takes that definition.

## front-page

The same configuration on the public Map. This is a Map page as a visitor sees it: no admin bar, no editing tools. The title and featured image come first; the map sits below.

## front-map

The map carries the Basemaps and Types from Settings. The layer switcher lists them.

## front-hover

Hover the control and both Basemaps are listed, along with the Types on offer: Photo, Camp and Green. The marker icons and colours come from those rows. The open panel is the visitor's view of the same configuration.

## front-hold

Change a Basemap or a Type once, and every Map follows.

## front-meta

Meta is defined in Settings too. Four fields — Description, Journal Entry, Date and Distance — sit in two groups, About and Details. Every Map uses the same fields and groups. The labels and groups come from Settings, not from this Map.
